# ความปลอดภัยด้านอาหารและการจัดการสารก่อภูมิแพ้

## SOP-FB-010 ความปลอดภัยด้านอาหารและสุขอนามัย

### สุขอนามัยส่วนบุคคล

ล้างมือด้วยสบู่และน้ำอุ่นอย่างน้อย 20 วินาที ในกรณีต่อไปนี้ ก่อนเริ่มงาน หลังเข้าห้องน้ำ หลังสัมผัสอาหารดิบ หลังสัมผัสเงิน โทรศัพท์ ผม หรือใบหน้า หลังจับจานเปื้อน หลังไอหรือจาม หลังทิ้งขยะ หลังสัมผัสสัตว์

ปิดแผลด้วยพลาสเตอร์กันน้ำสีฟ้าและสวมถุงมือทับ

**พนักงานที่มีอาการต่อไปนี้ห้ามปฏิบัติงานสัมผัสอาหาร** ท้องเสีย อาเจียน มีไข้ ดีซ่าน เจ็บคอร่วมกับมีไข้ หรือมีแผลติดเชื้อที่มือ ต้องรายงานหัวหน้างานทันที และกลับมาปฏิบัติงานได้เมื่อหายจากอาการอย่างน้อย 48 ชั่วโมง

ตรวจสุขภาพประจำปีตามที่กฎหมายกำหนดและเก็บบันทึกไว้ที่ฝ่ายบุคคล

### การควบคุมอุณหภูมิ

| ประเภท | ช่วงอุณหภูมิที่ปลอดภัย |
|---|---|
| ตู้เย็นเก็บอาหารสด | 0 – 5°C |
| ตู้แช่แข็ง | -18°C หรือต่ำกว่า |
| อาหารร้อนพร้อมเสิร์ฟ | 60°C ขึ้นไป |
| อาหารเย็นพร้อมเสิร์ฟ | 5°C หรือต่ำกว่า |
| **เขตอันตราย (danger zone)** | **5 – 60°C ห้ามทิ้งอาหารไว้ในช่วงนี้เกิน 2 ชั่วโมง** |
| การอุ่นอาหารซ้ำ | ต้องถึง 75°C ภายใน 2 ชั่วโมง และอุ่นซ้ำได้เพียง 1 ครั้ง |
| การละลายน้ำแข็ง | ในตู้เย็นเท่านั้น ห้ามละลายที่อุณหภูมิห้อง |

บันทึกอุณหภูมิวันละ 3 ครั้ง เช้า กลางวัน เย็น ลงแบบฟอร์ม F-03 พร้อมลายมือชื่อผู้บันทึก เก็บบันทึกไว้อย่างน้อย 6 เดือน เพราะเป็นหลักฐานเดียวที่ใช้ยืนยันได้เมื่อมีการสอบสวนกรณีอาหารเป็นพิษ

### การป้องกันการปนเปื้อนข้าม

- แยกเขียงและมีดตามระบบสี แดง เนื้อดิบ / น้ำเงิน อาหารทะเลดิบ / เหลือง สัตว์ปีกดิบ / เขียว ผักผลไม้ / ขาว อาหารปรุงสุกและเบเกอรี่
- จัดเก็บในตู้เย็นตามลำดับ **อาหารพร้อมรับประทานชั้นบนสุด เนื้อดิบและสัตว์ปีกชั้นล่างสุด** เพื่อไม่ให้น้ำจากเนื้อดิบหยดลงบนอาหารพร้อมรับประทาน
- ปิดฝาและติดฉลากทุกภาชนะ ระบุชื่ออาหาร วันที่ผลิต วันหมดอายุ
- ใช้หลัก FIFO (first in, first out) ในการเบิกจ่ายวัตถุดิบทุกครั้ง

### การเก็บตัวอย่างอาหาร

เก็บตัวอย่างอาหารทุกเมนูที่ให้บริการในบุฟเฟต์และงานจัดเลี้ยง อย่างน้อย 100 กรัม ในภาชนะปิดสนิทติดฉลากวันที่และชื่อเมนู เก็บที่ 0–5°C เป็นเวลา **48 ชั่วโมง** เพื่อใช้ตรวจสอบกรณีเกิดอาการเจ็บป่วยจากอาหาร

### การควบคุมสัตว์พาหะ

ตรวจและปิดช่องทางเข้าของแมลงและสัตว์ทุกวัน ไม่เก็บอาหารบนพื้น ต้องวางบนชั้นสูงจากพื้นอย่างน้อย 15 ซม. ทิ้งขยะในถังที่มีฝาปิดและนำออกจากพื้นที่ครัวอย่างน้อยวันละ 2 ครั้ง ประสานผู้รับเหมากำจัดแมลงตามรอบและเก็บรายงานไว้ตรวจสอบ

**ข้อควรระวังเฉพาะของรีสอร์ทนี้** เนื่องจากมีสวนพฤกษศาสตร์และมุมสัตว์เลี้ยง (Animal Village) ต้องเข้มงวดเป็นพิเศษเรื่องการปิดคลุมอาหารในพื้นที่กลางแจ้ง และห้ามพนักงานที่สัมผัสสัตว์เข้าพื้นที่ครัวก่อนล้างมือและเปลี่ยนเครื่องแบบ

## SOP-FB-011 การจัดการสารก่อภูมิแพ้และความต้องการพิเศษด้านอาหาร

1. **สอบถามเรื่องการแพ้อาหารกับแขกทุกโต๊ะ** ก่อนรับออร์เดอร์ ไม่ใช่เฉพาะเมื่อแขกแจ้งเอง เพราะแขกจำนวนมากคิดว่าครัวรู้อยู่แล้วหรือไม่กล้าเอ่ย
2. สารก่อภูมิแพ้หลักที่ต้องระบุ ธัญพืชที่มีกลูเตน สัตว์น้ำเปลือกแข็ง (กุ้ง ปู) ปลา ไข่ ถั่วลิสง ถั่วเปลือกแข็ง ถั่วเหลือง นม งา ซัลไฟต์
3. **ห้ามเดา ห้ามคาดคะเน** หากไม่แน่ใจในส่วนผสมให้สอบถามเชฟก่อนตอบแขกทุกครั้ง
4. แจ้งครัว 2 ช่องทางเสมอ บันทึกในระบบ POS **และ** แจ้งด้วยวาจากับเชฟประจำสถานี
5. ครัวต้องเตรียมอาหารสำหรับแขกที่แพ้ในพื้นที่แยก ใช้อุปกรณ์และเขียงที่ล้างสะอาดแล้ว และเปลี่ยนถุงมือใหม่
6. ใช้จานหรือฝาครอบที่มีสัญลักษณ์แตกต่าง และพนักงานที่รับออร์เดอร์ควรเป็นผู้เสิร์ฟด้วยตนเอง
7. ยืนยันกับแขกอีกครั้งขณะเสิร์ฟ เช่น "จานนี้ปราศจากถั่วตามที่แจ้งไว้นะคะ"
8. **กรณีแขกมีอาการแพ้** หยุดการรับประทานทันที แจ้ง Duty Manager และฝ่ายรักษาความปลอดภัย เรียกรถพยาบาลหากมีอาการรุนแรงเช่นหายใจลำบากหรือบวมที่ใบหน้าหรือลำคอ เก็บตัวอย่างอาหารที่เหลือไว้ทั้งหมด และบันทึก Incident Report (F-10)
9. **อาหารฮาลาล** จัดเก็บ ปรุง และเสิร์ฟด้วยอุปกรณ์แยกเฉพาะ ไม่ปะปนกับผลิตภัณฑ์จากสุกรและแอลกอฮอล์ ระบุแหล่งที่มาของวัตถุดิบที่ได้รับการรับรอง
10. **อาหารสำหรับเด็ก** มีเมนูเด็ก ที่นั่งเด็ก และอุปกรณ์สำหรับเด็ก พร้อมบริการอุ่นนมและน้ำร้อนสำหรับชงนมโดยไม่คิดค่าใช้จ่าย

การเขี่ยส่วนผสมออก การล้างน้ำ หรือการหยิบออกจากจานที่ปรุงแล้ว **ไม่ถือเป็นการทำอาหารปลอดสารก่อภูมิแพ้** ต้องปรุงใหม่ทั้งจานเสมอ
