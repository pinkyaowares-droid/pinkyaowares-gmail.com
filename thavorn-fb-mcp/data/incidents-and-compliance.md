# การปฏิบัติตามกฎหมาย ข้อร้องเรียน และเหตุฉุกเฉิน

## SOP-FB-012 การจำหน่ายเครื่องดื่มแอลกอฮอล์อย่างรับผิดชอบ

### ข้อกำหนดตามกฎหมาย

1. **ห้ามจำหน่ายแก่ผู้มีอายุต่ำกว่า 20 ปีบริบูรณ์** ตรวจบัตรประจำตัวประชาชนหรือหนังสือเดินทางเมื่อแขกดูอายุน้อยกว่า 25 ปี ใช้หลัก "ไม่แน่ใจ ให้ขอดูบัตร" การที่ผู้ปกครองอนุญาตไม่ใช่ข้อยกเว้น
2. ห้ามจำหน่ายแก่ผู้ที่มีอาการมึนเมาจนครองสติไม่ได้
3. ปฏิบัติตามข้อจำกัดเรื่องเวลาและวันห้ามจำหน่ายตามพระราชบัญญัติควบคุมเครื่องดื่มแอลกอฮอล์และประกาศที่เกี่ยวข้อง
4. ห้ามโฆษณาหรือส่งเสริมการขายในลักษณะที่ขัดต่อกฎหมาย
5. แสดงป้ายเตือนตามที่กฎหมายกำหนดในจุดจำหน่ายทุกแห่ง

### ข้อควรระวังสำคัญเรื่องเวลาจำหน่าย

กฎเกณฑ์เรื่องเวลาห้ามจำหน่าย วันสำคัญทางศาสนา และข้อยกเว้นสำหรับสถานประกอบการที่จดทะเบียนตามกฎหมายว่าด้วยโรงแรม **มีการแก้ไขเปลี่ยนแปลงเป็นระยะ** ห้ามระบุช่วงเวลาเป็นข้อเท็จจริงจากความจำ

ให้ฝ่ายกฎหมายหรือผู้จัดการทั่วไปตรวจสอบสถานะใบอนุญาตและประกาศฉบับล่าสุดกับสำนักงานสาธารณสุขจังหวัดภูเก็ตและหน่วยงานที่เกี่ยวข้อง แล้วจัดทำเป็นภาคผนวก ก. พร้อมระบุวันที่ปรับปรุงล่าสุด และแจ้งพนักงานทุกครั้งที่มีการเปลี่ยนแปลง

### การจัดการแขกที่ดื่มมากเกินไป

1. สังเกตสัญญาณเตือน พูดไม่ชัด เดินเซ ตาแดงเหม่อลอย เสียงดังผิดปกติ พฤติกรรมก้าวร้าว
2. ชะลอการเสิร์ฟ เสนอน้ำเปล่าและอาหารว่างแทน
3. ปฏิเสธการเสิร์ฟเพิ่มด้วยถ้อยคำสุภาพและไม่ทำให้แขกเสียหน้า พูดในที่ส่วนตัว ไม่ต่อหน้าแขกอื่น
4. แจ้ง Duty Manager ทันที และประสานฝ่ายรักษาความปลอดภัย
5. ช่วยเหลือแขกกลับห้องพักอย่างปลอดภัย หากเป็นแขกภายนอกให้เสนอเรียกรถแท็กซี่
6. บันทึกเหตุการณ์ใน logbook (F-15) ทุกครั้ง
7. **ห้ามพนักงานโต้เถียงหรือใช้กำลังกับแขกโดยเด็ดขาด**

## SOP-FB-013 การจัดการข้อร้องเรียนของแขก (LEARN)

| ขั้นตอน | การปฏิบัติ |
|---|---|
| **L — Listen** | ตั้งใจฟังจนจบ สบตา พยักหน้า ไม่ขัดจังหวะ ไม่แก้ตัว |
| **E — Empathize** | แสดงความเข้าใจ "ดิฉันเข้าใจความรู้สึกของท่านค่ะ และขออภัยในความไม่สะดวกที่เกิดขึ้น" |
| **A — Apologize** | กล่าวขอโทษอย่างจริงใจในนามของโรงแรม โดยไม่โทษแผนกอื่นหรือเพื่อนร่วมงาน |
| **R — React** | ลงมือแก้ไขทันที แจ้งแขกว่าจะทำอะไรและใช้เวลาเท่าใด |
| **N — Notify** | แจ้งหัวหน้างาน บันทึกลงระบบ และติดตามผล |

### แนวปฏิบัติเพิ่มเติม

1. **แก้ไขทันทีในจุดเกิดเหตุ** อย่าปล่อยให้แขกต้องร้องเรียนซ้ำหรือรอนาน
2. พนักงานทุกคนมีอำนาจแก้ไขปัญหาเบื้องต้นได้ทันที เช่น เปลี่ยนอาหารที่ไม่เป็นไปตามมาตรฐาน เสิร์ฟเครื่องดื่มหรือของหวานชดเชย
3. การยกเลิกรายการในบิลหรือให้ส่วนลดต้องได้รับอนุมัติจากหัวหน้างานขึ้นไป และบันทึกเหตุผลทุกครั้ง (F-14)
4. **อาหารไม่ถูกใจ** เสนอเปลี่ยนเมนูใหม่ทันที ไม่ถามย้ำหรือทำให้แขกรู้สึกผิด สอบถามข้อมูลเพิ่มเติมเพื่อนำไปปรับปรุง
5. **รอนาน** แจ้งความคืบหน้าเชิงรุกทุก 5 นาที เสนอเครื่องดื่มหรือของว่างระหว่างรอ การเงียบทำให้แขกโกรธมากกว่าการรอเอง
6. **พบสิ่งแปลกปลอมในอาหาร** เก็บอาหารและสิ่งแปลกปลอมไว้เป็นหลักฐาน แจ้ง Executive Chef และ Duty Manager ทันที จัดทำ Incident Report ยกเลิกรายการในบิล และติดตามอาการของแขก
7. ติดตามผลกับแขกก่อนเช็คเอาต์ และรายงานสรุปข้อร้องเรียนประจำสัปดาห์ต่อฝ่ายบริหาร
8. ตอบกลับรีวิวออนไลน์ที่เกี่ยวกับอาหารและเครื่องดื่มภายใน 48 ชั่วโมง โดยผู้ที่ได้รับมอบหมายเท่านั้น

## SOP-FB-017 ความปลอดภัยและเหตุฉุกเฉิน

### ความปลอดภัยในการทำงาน

เช็ดพื้นที่เปียกทันทีและวางป้ายเตือนพื้นลื่น / ยกของหนักด้วยการงอเข่า ไม่ก้มหลัง ของหนักเกิน 20 กก. ใช้ 2 คนหรืออุปกรณ์ช่วย / ใช้ผ้าหนาแห้งจับภาชนะร้อน ห้ามใช้ผ้าเปียก / ถือมีดโดยหันปลายลง เดินชิดข้างทาง ไม่พยายามรับมีดที่ตกกลางอากาศ / แจ้งซ่อมอุปกรณ์ชำรุดทันทีและติดป้ายห้ามใช้งาน

### เหตุฉุกเฉิน

| สถานการณ์ | การปฏิบัติ |
|---|---|
| **ไฟไหม้** | แจ้งเหตุ กดสัญญาณเตือน ใช้ถังดับเพลิงหากควบคุมได้ ปิดแก๊ส อพยพแขกตามเส้นทางหนีไฟไปยังจุดรวมพล |
| **แขกสำลักอาหาร** | ปฐมพยาบาลด้วยวิธี Heimlich maneuver โดยผู้ที่ผ่านการอบรม เรียกทีมปฐมพยาบาลและรถพยาบาลทันที |
| **แขกแพ้อาหารรุนแรง** | ปฏิบัติตาม SOP-FB-011 ข้อ 8 เรียกรถพยาบาลทันทีหากหายใจลำบาก |
| **ไฟฟ้าดับ** | เปิดไฟฉุกเฉิน สร้างความมั่นใจให้แขก งดใช้ลิฟต์ ไม่เปิดประตูตู้เย็นเพื่อรักษาอุณหภูมิอาหาร |
| **อุบัติเหตุพนักงาน** | ปฐมพยาบาล นำส่งพยาบาล บันทึกรายงานอุบัติเหตุภายใน 24 ชั่วโมง |
| **สภาพอากาศรุนแรง คลื่นลมแรง** | ปิดบริการพื้นที่กลางแจ้งและชายหาด ย้ายแขกเข้าพื้นที่ในร่ม ตามคำสั่ง Duty Manager |
