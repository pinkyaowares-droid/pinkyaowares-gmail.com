# การบริหารจัดการ จัดเลี้ยง ต้นทุน และการอบรม

## SOP-FB-014 บริการจัดเลี้ยงและงานพิเศษ (Banquet & Events)

ครอบคลุมงานประชุมสัมมนา งานแต่งงาน Romantic Dining ริมชายหาด และงานเลี้ยงส่วนตัว

### ก่อนงาน

1. รับ Banquet Event Order (BEO, F-11) จากฝ่ายขายอย่างน้อย **7 วันก่อนงาน** และยืนยันรายละเอียดกับลูกค้าอีกครั้ง 48 ชั่วโมงก่อนงาน
2. ตรวจสอบจำนวนแขกรับประกัน (guaranteed number) ผังห้อง เมนู เครื่องดื่ม อุปกรณ์โสตทัศนูปกรณ์ เวลา และข้อจำกัดด้านอาหาร
3. ประชุมประสานงานระหว่าง F&B ครัว ช่าง แม่บ้าน และฝ่ายรักษาความปลอดภัย
4. **เตรียมอาหารเผื่อ 5–10%** จากจำนวนแขกรับประกัน
5. **งานกลางแจ้งริมชายหาดหรือในสวน** ต้องมีแผนสำรองกรณีฝนตก (wet weather plan) ที่ระบุสถานที่สำรองชัดเจน และตรวจพยากรณ์อากาศ 24 ชั่วโมงก่อนงาน สำคัญเป็นพิเศษในฤดูฝนของภูเก็ต พฤษภาคมถึงตุลาคม
6. จัดสถานที่ให้แล้วเสร็จอย่างน้อย **2 ชั่วโมง** ก่อนเริ่มงาน และให้หัวหน้างานตรวจตาม checklist

### ระหว่างงาน

- ประชุมทีมก่อนงาน 30 นาที มอบหมายพื้นที่รับผิดชอบและลำดับการเสิร์ฟ
- อัตราส่วนพนักงาน **1 คนต่อแขก 15 คน** สำหรับบุฟเฟต์ **1 คนต่อแขก 10 คน** สำหรับ set menu
- เสิร์ฟพร้อมกันทั้งโต๊ะโดยใช้สัญญาณจากหัวหน้างาน
- เติมน้ำและเครื่องดื่มสม่ำเสมอโดยไม่รบกวนพิธีการ
- Event Captain ต้องอยู่ใกล้ผู้จัดงานตลอดเวลาเพื่อรับคำสั่งเปลี่ยนแปลง
- งานริมชายหาด ตรวจไฟส่องสว่าง ทางเดิน ความมั่นคงของโครงสร้าง และเตรียมยากันยุง

### หลังงาน

สรุปรายการที่เกิดขึ้นจริงกับผู้จัดงานและให้ลงลายมือชื่อยืนยันในบิล ขอบคุณลูกค้าและสอบถามความพึงพอใจ เก็บและทำความสะอาดพื้นที่ภายในเวลาที่กำหนด ตรวจนับอุปกรณ์และรายงานความเสียหายหรือของสูญหาย จัดทำ event debrief ภายใน 24 ชั่วโมง

## SOP-FB-015 สินค้าคงคลังและการควบคุมต้นทุน

1. **การเบิกจ่าย** ทุกจุดบริการเบิกตามใบเบิก (F-05) ที่มีลายมือชื่ออนุมัติ ในเวลาที่คลังกำหนดเท่านั้น
2. **การรับสินค้า** ตรวจปริมาณ คุณภาพ อุณหภูมิ วันหมดอายุ และเอกสารกำกับ **ปฏิเสธการรับสินค้าที่ไม่ได้มาตรฐานทันที** และบันทึกในรายงาน
3. อาหารแช่เย็นต้องมาถึงที่ไม่เกิน 5°C อาหารแช่แข็งไม่เกิน -18°C มิฉะนั้นให้ปฏิเสธ
4. **การจัดเก็บ** ใช้หลัก FIFO ติดฉลากวันที่รับทุกรายการ จัดเก็บแยกประเภทอย่างเป็นระเบียบ
5. **การนับสต็อก** นับประจำวันสำหรับสินค้ามูลค่าสูง สุรา ไวน์ อาหารทะเล เนื้อนำเข้า และนับเต็มรูปแบบทุกสิ้นเดือน
6. **การบันทึกของเสีย** บันทึกทุกรายการใน wastage report (F-06) พร้อมเหตุผล
7. **อาหารพนักงานและอาหารทดลอง** ต้องมีใบบันทึกแยกจากยอดขาย
8. **เป้าหมายต้นทุน** ต้นทุนอาหารไม่เกิน 30–33% ของยอดขายอาหาร ต้นทุนเครื่องดื่มไม่เกิน 20–25% ของยอดขายเครื่องดื่ม ตัวเลขนี้เป็นค่ามาตรฐานอุตสาหกรรม ต้องปรับตามงบประมาณจริงของโรงแรม
9. วิเคราะห์ความนิยมและกำไรของแต่ละเมนู (menu engineering) ทุกไตรมาส และปรับปรุงเมนูตามผลวิเคราะห์
10. **การลดขยะอาหาร** ชั่งและบันทึกปริมาณขยะอาหารทุกวัน แยกขยะอินทรีย์ ลดพลาสติกใช้ครั้งเดียว และใช้วัตถุดิบท้องถิ่นตามแนวทางความยั่งยืนของรีสอร์ท

## SOP-FB-018 การฝึกอบรมและการประเมินผล

1. **ปฐมนิเทศพนักงานใหม่** 3 วันแรก ครอบคลุมความรู้เกี่ยวกับโรงแรม ความปลอดภัยด้านอาหาร มาตรฐานการบริการ และการใช้ระบบ POS
2. **ระยะทดลองงาน** ประเมินที่ 30 60 และ 90 วัน โดยหัวหน้างานโดยตรง
3. **การอบรมประจำเดือน** อย่างน้อย 2 ชั่วโมงต่อเดือน หัวข้อหมุนเวียน ความรู้เมนู ความรู้ไวน์ การจัดการข้อร้องเรียน ภาษาอังกฤษเพื่อการบริการ ความปลอดภัยด้านอาหาร
4. **การทดสอบความรู้เมนู** ทุกครั้งที่เปลี่ยนเมนู พนักงานทุกคนต้องผ่านการชิมและทดสอบก่อนขึ้นปฏิบัติงาน
5. **การประเมินประจำปี** ใช้เกณฑ์มาตรฐานการบริการ ยอดขายเฉลี่ยต่อหัว คะแนนความพึงพอใจของแขก และการปฏิบัติตาม SOP
6. **การตรวจสอบภายใน** หัวหน้างานสุ่มตรวจการปฏิบัติตาม SOP อย่างน้อยเดือนละ 1 ครั้งต่อจุดบริการ และจัดทำ mystery guest audit ปีละ 2 ครั้ง
7. เก็บบันทึกการอบรมทั้งหมดในแฟ้มประวัติพนักงาน (F-12)

## SOP-FB-019 ตัวชี้วัดผลการดำเนินงาน (KPI)

| ตัวชี้วัด | เป้าหมาย | ความถี่ |
|---|---|---|
| คะแนนความพึงพอใจด้าน F&B | ≥ 4.5 / 5.0 | รายเดือน |
| คะแนนรีวิวออนไลน์ที่กล่าวถึงอาหาร | ≥ 4.5 / 5.0 | รายเดือน |
| ยอดขายเฉลี่ยต่อแขก (average check) | ตามงบประมาณ | รายวัน |
| อัตราการเข้าใช้บริการ (capture rate) | ตามงบประมาณ | รายเดือน |
| ต้นทุนอาหาร | ≤ 33% | รายเดือน |
| ต้นทุนเครื่องดื่ม | ≤ 25% | รายเดือน |
| เวลาส่งอาหารในห้องพักตรงมาตรฐาน | ≥ 95% | รายสัปดาห์ |
| ผลการตรวจสุขาภิบาลอาหาร | ≥ 90% | รายไตรมาส |
| ข้อร้องเรียนที่แก้ไขไม่สำเร็จ | 0 | รายเดือน |
| อัตราการลาออกของพนักงาน | ≤ 20% ต่อปี | รายปี |
| ปริมาณขยะอาหารต่อแขกหนึ่งคน | ลดลง 10% เทียบปีก่อน | รายเดือน |

ตัวเลขเป้าหมายทั้งหมดเป็นค่าตั้งต้น ต้องได้รับการยืนยันจากฝ่ายบริหารก่อนใช้ประเมินผลจริง
