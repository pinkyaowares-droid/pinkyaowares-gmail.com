# Thavorn F&B SOP — MCP Server

MCP server ที่เปิดคู่มือมาตรฐานการปฏิบัติงานแผนกอาหารและเครื่องดื่มของ Thavorn Palm Beach Resort ให้ Claude ค้นและอ้างอิงได้ระหว่างสนทนา

## ติดตั้ง

ต้องมี Python 3.10 ขึ้นไป

```bash
cd thavorn-fb-mcp
python -m venv .venv
source .venv/bin/activate          # Windows ใช้ .venv\Scripts\activate
pip install -r requirements.txt
python test_server.py              # ต้องขึ้น ALL PASSED
```

## ต่อกับ Claude Desktop

เปิด Settings → Developer → Edit Config แล้วเพิ่มส่วนนี้ลงใน `claude_desktop_config.json`

```json
{
  "mcpServers": {
    "thavorn-fb-sop": {
      "command": "/absolute/path/to/thavorn-fb-mcp/.venv/bin/python",
      "args": ["/absolute/path/to/thavorn-fb-mcp/server.py"]
    }
  }
}
```

ต้องเป็น path เต็มทั้งสองบรรทัด path แบบย่อหรือ path สัมพัทธ์จะไม่ทำงานเพราะ Claude Desktop รันจากไดเรกทอรีอื่น บน Windows ใช้ `.venv\\Scripts\\python.exe` และใส่ backslash คู่

ปิดแล้วเปิด Claude Desktop ใหม่ ถ้าต่อสำเร็จจะเห็นไอคอนเครื่องมือในช่องพิมพ์

## เครื่องมือที่มี

| Tool | ใช้ทำอะไร |
|---|---|
| `search_sop` | ค้นคู่มือด้วยคำค้นไทยหรืออังกฤษ เป็นตัวหลักที่ควรเรียกก่อนตอบทุกครั้ง |
| `get_sop` | ดึงเนื้อหาเต็มของ SOP หนึ่งหัวข้อ รับได้ทั้ง `SOP-FB-011`, `011` และ `11` |
| `list_sops` | ดูภาพรวมหัวข้อทั้งหมด กรองตามหมวดได้ |
| `get_reference_table` | ทางลัดไปตารางที่เรียกดูบ่อย อุณหภูมิ เวลาเสิร์ฟ ไวน์ แบบฟอร์ม KPI เบอร์ฉุกเฉิน |
| `get_critical_rules` | กฎที่ไม่มีข้อยกเว้น และรายการที่ต้องยืนยันก่อนนำไปใช้จริง |

นอกจากนี้เปิดไฟล์คู่มือทั้งไฟล์ได้ผ่าน resource `sop://{ชื่อไฟล์}` เช่น `sop://food-safety`

## ตัวอย่างคำถามที่ใช้ได้

- แขกบ่นว่ารออาหาร 40 นาทีแล้ว ทำยังไง
- เสิร์ฟไวน์แดงอุณหภูมิเท่าไหร่
- แขกอายุ 17 สั่งเบียร์ที่พูลบาร์
- อาหารบุฟเฟต์วางได้นานแค่ไหน
- ขอเชคลิสต์ปิดร้าน Ocean Rhyme
- แก้วแตกในสระต้องทำอะไรบ้าง

## การแก้ไขเนื้อหา

เนื้อหาทั้งหมดอยู่ในโฟลเดอร์ `data/` เป็นไฟล์ Markdown ธรรมดา แก้ได้โดยไม่ต้องแตะโค้ด

- หัวข้อใหม่ให้ขึ้นต้นด้วย `## SOP-FB-0XX ชื่อหัวข้อ` server จะจับรหัสให้อัตโนมัติ
- หัวข้อที่ไม่มีรหัสก็ค้นเจอได้ แต่จะเรียกด้วย `get_sop` ไม่ได้
- คำพ้องที่พนักงานพูดติดปากแต่ไม่มีในเนื้อหา ให้เพิ่มใน `SYNONYMS` ใน `server.py` เพื่อให้ค้นเจอ
- แก้เสร็จให้รัน `python test_server.py` อีกครั้ง แล้วรีสตาร์ต Claude Desktop

## ข้อจำกัดที่ควรรู้

การค้นหาใช้การเทียบตัวอักษรแบบ n-gram ไม่ได้ตัดคำไทยจริง จึงอาจพลาดคำที่สะกดต่างจากในคู่มือมาก ถ้าเจอคำถามที่ค้นไม่เจอบ่อย ๆ ให้เพิ่มคำนั้นเข้า `SYNONYMS` ซึ่งได้ผลกว่าการปรับสูตรคะแนน

คู่มือนี้ยังไม่ผ่านการอนุมัติจากผู้จัดการทั่วไป เวลาห้ามขายแอลกอฮอล์ ตัวเลขต้นทุน และเบอร์ติดต่อภายในยังต้องยืนยัน ดูรายละเอียดได้จาก `get_critical_rules`
